Full Feature Set

18 capabilities, zero code

Every tool below ships on every plan tier — higher plans simply raise the limits.

Drag & Drop Builder

Assemble pages by dragging components onto a free-form canvas with smart guides and snap-to-grid. Reorder, resize, and nest elements exactly the way a designer would.

Visual App Editor

Edit text inline, restyle with a full properties panel, and see the result instantly. What you see in the editor is byte-for-byte what your users get.

Pre-Built Components

120+ production-grade components: navbars, tables, charts, forms, galleries, checkouts. Each one is accessible, themeable, and responsive out of the box.

Responsive Design

Layouts adapt automatically to desktop, tablet, and mobile breakpoints. Override any property per device when you need pixel-level control.

Database Management

Model collections, fields, and relations visually — no SQL required. Row-level permissions keep every record visible only to the right users.

API Integration

Connect any REST endpoint with auth headers, pagination, and field mapping. Bind responses straight to tables, charts, and repeating lists.

Authentication

Ship sign-up, login, password reset, and role-based access in minutes. SSO, magic links, and social login are included on Pro and Business plans.

Workflow Automation

Chain triggers, conditions, and actions on a visual logic canvas. Send emails, call webhooks, and update records the moment something happens.

Form Builder

Build multi-step forms with validation, conditional fields, and file uploads. Submissions land in your database and can trigger any workflow.

Custom Branding

Define brand colors, typography, radii, and logos once — every component inherits them. Agencies can white-label the entire published app.

Analytics

Track visitors, conversions, and top pages with a built-in, privacy-friendly dashboard. No tracking scripts to install, no cookie banners forced on you.

Team Collaboration

Invite teammates with Owner, Editor, or Viewer roles and build together in real time. Comments and mentions keep feedback attached to the exact element.

Version History

Every publish creates a named, restorable snapshot — and the editor autosaves as you work. Roll back any page or the whole app in one click.

App Preview

Preview on desktop, tablet, and phone frames without leaving the builder. Share a private preview link so stakeholders can review before launch.

Publishing

Deploy to a global edge network with automatic SSL in one click. Connect custom domains and roll back to any previous version instantly.

Template Marketplace

Start from 120+ hand-crafted templates for CRMs, stores, portals, and dashboards. Every template includes pages, components, and a ready data model.

AI Assist

Describe a page in plain English — "pricing page with three tiers and an FAQ" — and get a first draft on the canvas. AI also suggests copy, color pairs, and layout fixes as you build.

Payments & Subscriptions

Accept one-time payments, subscriptions, and invoices with built-in Stripe and regional gateway blocks. Checkout, receipts, and dunning emails work out of the box.
